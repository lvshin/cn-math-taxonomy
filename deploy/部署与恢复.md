# 家庭学习服务部署与恢复

应用为独立 Java 25 / Spring Boot 3.5.16 工程，公开源码只含通用程序与课程内容。真实域名、账号映射、密钥、连接地址、备份和截图保存在受保护的部署目录。数据库要求 PostgreSQL 18.x；允许同主版本补丁更新。身份系统保留原数据库，不随本应用迁移。

## 先验证，再开放

1. 只读核对现有 ECS 的内存、磁盘、端口、数据库版本、建库权限、DNS、证书及域名接入条件。资源不足则停止部署，不购买资源或替换其他业务库。
2. 使用 JDK 25 独立构建 `mvn -f server/pom.xml clean verify`。运行前端测试、真实 PG18 集成检查、身份 Provider 隔离检查及真实后端联合验收。身份扩展用 JDK25构建 Java21 字节码，以匹配 Keycloak26.7.3 官方运行时。
3. 为应用建立独立业务库，撤销 PUBLIC CONNECT；分别创建 `learning_migrator`、`learning_app`、`learning_backup`。三个账号都不用超级用户或 BYPASSRLS，运行账号不拥有业务表。只授予指定库连接，迁移账号可建学习 schema。迁移 V2 为备份账号配置只读全表策略；该账号不能用于 Web。
4. 真实配置写到仓库之外，目录700、文件600。参考 `应用环境示例.env`；OIDC 回调精确到 `/edu/math/login/oauth2/code/learning`，启用 PKCE S256，统一退出回调按后端配置设置。运营管理员必须用已核对的 issuer/sub，不能按重名用户名自动合并。
5. 先使用独立、受保护的一次性迁移配置运行 Flyway，该配置才包含 `DB_MIGRATION_USER` 和 `DB_MIGRATION_PASSWORD`。迁移实例不接公网，确认迁移成功后停止；正式 Web 配置设 `SPRING_FLYWAY_ENABLED=false`，并删除 Web 环境中的两项迁移凭据，再启动 Web。`compose.yaml` 默认禁止 Web 自动迁移；不能将迁移配置文件挂给 Web。后续升级同样先备份、单独迁移、再发布。初次迁移后建立完整备份并恢复验证；发布 Provider 前另备份既有身份库与客户端/注册流配置。不得重新导入 Realm、重建既有账号或客户端。
6. 将 Provider 加入匹配版本的身份镜像，连接私有回调网络。内部专用密钥用于 reserve/bind及注册续办凭据签名，Provider 回调根地址包含 `/edu/math`。完成联合验收后，用 `identity-provider/scripts/configure_flow.py` 增量添加 REQUIRED 门禁与教育客户端专属凭据claim，最后启用注册；其他客户端无邀请注册均被门禁拒绝，已有登录保持原样。
7. 用 JDK25运行 `APP_IMAGE=learning:verified python3 deploy/build-image.py`，它编译轻量 readiness 探针，并打包已验证的后端JAR。可用 `JAVA_RUNTIME` 指定已验证的Java25运行时镜像，生产固定测试过的标签或摘要。`deploy/compose.yaml` 中只绑定回环端口，使用现有代理网络和私有身份回调网络，非root、只读文件系统、资源上限、健康检查与日志轮换。
8. HTTPS 代理只转发 `/edu/math/*`，先拒绝 `/edu/math/internal` 和 `/edu/math/internal/*`，避免 Provider 内部接口公网开放。代理覆盖可信的转发头，不能将客户端伪造头直接传给应用。根路径可以重定向到 `/edu/math/`。保留其他域名配置，先 validate 再 reload。
9. 从真实域名验证 HTTPS、匿名API401、CSRF拒绝、OIDC精确回调、受邀注册、显式接受邀请、家庭管理/孩子切换、统一退出。既有网站、日历、通知与提醒完成受影响回归；不发送真实测试通知或把合成学习记录当作家庭事实。

## 单家庭规则升级

单家庭迁移仅对启用的成员关系建立唯一索引，历史退出、被移除的成员与原署名记录保留。升级前用具有完整只读策略的备份账号检查是否存在同一账号的多个启用成员关系；存在冲突则停止升级、由部署方核对，不自动删除或合并家庭。先完成可恢复备份，再执行独立迁移和应用更新。旧应用回退仍会受数据库唯一索引保护；正常回退保留索引和学习记录。

## 备份

`ops/backup.py` 使用独立只读备份账号、PG18客户端和同一 REPEATABLE READ 快照，先取得各表计数，再生成完整 custom-format 备份及SHA256清单。包含 `public.flyway_schema_history`，不能只备份 learning schema 后重新运行初始迁移。使用专门全行策略配合 `--enable-row-security`，并检查每张RLS表具有适用的全行 SELECT 策略、没有适用的限制策略，备份角色没有表写权限；否则拒绝备份，避免计数与归档同时被过滤而误报完整。不使用运行账号的家庭过滤视图；恢复逐表计数验证是完整性门禁。

受保护的 `LEARNING_PG_ENV` 是 PG 客户端 env 文件，包含 PGHOST/PGPORT/PGDATABASE/PGUSER/PGPASSWORD/PGSSLMODE。仅在已验证数据库支持TLS时配置 `verify-full` 与可信 CA；数据库不支持TLS时限定私网连接并在私有部署记录保留该事实，不自动修改其他业务的数据库参数。不能把密码放命令行。备份目录 `LEARNING_BACKUP_DIR` 权限700，文件600，不能挂到 Web 容器或公开目录；可使用 `LEARNING_PG_IMAGE` 固定客户端摘要，`LEARNING_PG_NETWORK` 选择私网。

```sh
python3 ops/backup.py
LEARNING_RESTORE_ADMIN_ENV=/protected/restore-admin.env python3 ops/verify_restore.py /protected/backups/learning-TIMESTAMP.dump
```

恢复验证只创建新UUID数据库，初始禁止连接，撤销 PUBLIC CONNECT后再开放给验证角色；使用单个恢复事务导入完整归档，临时授备份账号读取，重新检查全行读取条件并比对快照计数。成功后仅清理本次创建的测试库，失败保留受保护的测试库供核对，不覆盖已有数据库。验证管理员须有 CREATEDB，且同一集群存在策略涉及的三个角色；不能用 Web 或备份账号充当验证管理员。只使用自己产生、校验通过且受保护的归档，不能用该管理权限恢复第三方转来的未知dump。首次上线及每次迁移均运行恢复演练；清单 `restoreVerified` 为true才代表实际恢复通过。

系统服务样例每天备份、每5分钟探测 readiness；部署方将脚本安装到 `/opt/learning/ops/`，将私有运维环境安装到 `/etc/learning/operations.env` 后启用 timer。失败由 systemd 服务状态和 journal 明确记录；接外部通知需使用已有授权的运维渠道。无自动删除备份，定期检查空间、留存与受保护异地副本。单机备份不能抵御整机磁盘损坏。

## 回退与真实恢复

应用回退只切换至上一已验证镜像，保留现有业务库和新增记录。向前兼容的表不删除。身份扩展回退先关闭受控注册，再恢复原注册流和镜像；保留新增身份及学习记录，不能将整个身份库回滚到旧备份。

灾难恢复先停止新写入，将经过恢复验证的完整备份恢复到新库。表与函数归 `learning_migrator`，重授运行账号的 schema/function/table 权限以及备份账号只读权限，检查 FORCE RLS、复合外键、版本、账号安全属性和所有家庭计数。核对恢复点之后的记录去向，明确数据差距，再切换私有连接配置；不得直接用旧库覆盖当前写入。

教材本机入口保留浏览与旧JSON导出。云端为唯一可编辑长期历史源，导入必须预览并明确选家庭与孩子，不自动上传 Vault、教材PDF或测试记录。

## 30天记住我

保持应用本地60分钟会话，通过统一登录中心的原生持久SSO恢复，不新增长期认证令牌或会话数据库。部署方先运行真实Keycloak记住我及应用重启联验，备份身份配置和数据库，再使用 `identity-provider/scripts/configure_remember_me.py` 增量修改 `rememberMe`、`ssoSessionIdleTimeoutRememberMe`、`ssoSessionMaxLifespanRememberMe` 三项为启用、2592000秒、2592000秒；普通超时、客户端、注册门禁及主题保留。默认命令只读；`--apply` 必须指定新的受保护恢复文件，不能重新导入Realm。

发布应用后核对返回提示Cookie只为非认证标记、`capabilities` 不缓存、S256与state/nonce、静默失败清理、浏览器持久Cookie恢复、应用重启及统一退出。已有普通SSO不能自动升级为记住我；本次须在完整登录页勾选一次。原生重新登录会退出该统一账号的旧应用会话，页面须明确说明，不以密码重验页代替该选择。

应用回退保留数据库，按需要用三字段恢复文件回退记住我策略。关闭记住我会使已选择记住我的SSO失效，因此仅在实际回退时执行；不通过恢复整库来撤销新登录或学习记录。
