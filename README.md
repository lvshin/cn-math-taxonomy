# 苏州小学数学知识地图

基于 [xiaoyang111222/cn-math-taxonomy](https://github.com/xiaoyang111222/cn-math-taxonomy) 的苏教版改编，按现有十二册苏教数学教材组织小学一至六年级入口。保留概念图谱、自适应练习和回溯路径，重新建立教材目录与知识点落位。

苏教版源码：[lvshin/cn-math-taxonomy · suzhou-primary](https://github.com/lvshin/cn-math-taxonomy/tree/suzhou-primary)。Fork 的 `main` 用于跟随原项目。

## 使用

程序包含可独立浏览的教材前端，以及可选的家庭学习云端服务。个人域名、网络映射、系统服务、私有导航、部署截图和家庭数据保存在仓库之外。

本机独立预览：

macOS 双击 `启动.command`，或在项目根目录运行：

```sh
python3 scripts/serve.py --port 8768
```

然后访问 <http://127.0.0.1:8768/>。不要直接双击 HTML。静态预览仅监听本机回环地址，不依赖外部 CDN、账号或付费 API。教材 PDF 不复制到应用，也不通过此服务分发。

**静态模式只浏览教材、图谱和亲子活动卡，不再新增或编辑学习历史。** 原浏览器旧记录保持原样，可在“家庭学习”入口导出JSON，再到云端明确选择家庭与孩子、预览后导入；不会自动迁移或覆盖原记录。

- **教材地图**：一至六年级、上下册入口，区分已核目录与四上暂选目录，并保留具体版本差异。
- **知识图谱**：按册次、单元、领域搜索；查看前置基础、后续概念和掌握标准；可点击图中节点继续探索。
- **亲子数学**：12张生活活动卡，数量、比较、分类、空间、规律、测量各2张，含材料、玩法、家长提示、观察方向及简化/变化玩法，可打印。
- **幼儿园亲子活动**：独立入口 `/edu/kindergarten/`，首批16张布鲁伊关联活动、8个主题；复用家庭和孩子档案，按模块独立查询活动记录。材料、玩法、家长提示、来源与家庭改编说明见 [幼儿园模块](docs/幼儿园模块.md)。
- **巩固练习**：从知识点或单元开始，默认10题，可选5、10、20题；支持的题型随机换数字，其余从固定题库抽取，候选不足时提前结束。
- **一键复习**：只从当前孩子直接尝试过的知识点选题。答对后降低整个题型族的权重，答错或暂时不会则提高；已答对内容仍有复现机会。
- **基础诊断**：保留原有诊断，一个目标最多2题；第一题错继续同目标，第二题错再追问基础；第二题答对记为不稳。巩固与复习答对后继续，不套用该结束规则。
- **范围小检查**：云端最多12题，只检查所选范围，不向范围外追问；未测点保留未测。
- **学习历史**：观察与练习按家庭、孩子独立保存，多设备接续。更正追加留痕；题目与活动保留当时内容快照，不按新版重新判分。

## 家庭学习云端

云端采用独立的 **Java 25 / Spring Boot 3.5.16** 后端、Spring Security OIDC、JDBC、Flyway和 **PostgreSQL 18.x**，不依赖内部父工程。前端仍使用原生JavaScript，与同源的 `/edu/math/api/v1/` 通信；静态预览的API探测返回404时自动进入浏览模式。

- 复用统一登录中心的用户名与密码，按 `issuer + subject` 识别身份；一个成人账号同时只属于一个家庭，一个家庭可以建立多个孩子档案。创建或加入后不能再创建或加入其他家庭；正常退出或被移除后，才能重新选择家庭。
- 统一登录页可勾选“记住我”，此浏览器最多30天免重复输入密码；浏览器关闭或学习站更新后会重新验证统一账号并自动恢复。未勾选时保留普通登录时长。主动退出后停止自动恢复；此前普通登录需退出并重新登录一次后勾选。
- 通过7天、单次使用、可撤销的邀请加入家庭。没有统一账号的受邀者可在Keycloak受控注册；注册完成后仍须明确接受邀请，不自动授予家庭权限。
- 家庭管理员管理成员、孩子、邀请与导出；记录成员新增记录并更正自己的观察；只读成员查看家庭资料。移除或自行离开后，下一次请求失去访问权；至少保留一名管理员。运营身份不自动取得家庭资料权限。
- 亲子观察区分独立完成、需要提示、共同完成、未尝试和暂停。练习开始即固定家庭和孩子，随后切换页面选项不会改变本轮归属；推断跳过的基础不作为长期掌握证据。
- 云端是可编辑长期历史的唯一来源。幂等请求避免重试产生重复记录，版本冲突返回409；断网时本页保留待保存内容并提示重试或导出，不能把未确认保存当作已完成同步。
- 家庭与孩子复合外键、接口授权和数据库FORCE RLS共同隔离数据；Web运行角色不拥有业务表、不使用超级用户或BYPASSRLS。会话Cookie为Secure、HttpOnly、SameSite=Lax，写请求校验CSRF，认证令牌不放入浏览器存储。

构建后端与注册扩展：

```sh
mvn -f server/pom.xml verify
mvn -f identity-provider/pom.xml verify
```

运行前需建立独立业务库、运行/迁移/备份账号及保密OIDC客户端，再从仓库之外注入配置。Keycloak扩展匹配26.7.3，使用JDK25构建Java21字节码以兼容该版本身份服务运行时。受邀开户包含提交后绑定、签名续办与预约账本，处理中断或响应丢失；内部注册接口不得经公网代理开放。

完整配置、真实测试前提与恢复方式分别见 [后端说明](server/README.md)、[注册扩展说明](identity-provider/README.md)、[部署与恢复](deploy/部署与恢复.md)及[接口约定](docs/云端接口约定.md)。部署示例保持通用；教材PDF、真实账号与学习记录均不进入公开仓库。

**这是可使用的第一版资料整理工具，知识点、先修关系、题目均未经教师审核。** 目录核对不等于教学内容全覆盖。有目录但未拆分的单元和活动保留空列表；不按人教版原顺序补齐苏教版空缺。结果区分直接作答、推断跳过、第二题通过、两题未通过和待确认，不据几题推断完整掌握或学习能力。

当前资料包含修订系列与现用2013系列，按所选文件组织，不统一标成2022课标版。下册“2013版”是采用的系列标签，文件后记所载2011课标与具体出版版次分开记录；版权版次仍未核定。六上扫描件和官网正式版目录不同，采用扫描目录不代表二者完全相同。四上目录及正文首尾相符，仍保持暂选。五上本地目录与官网相符，但未含完整前页。所有扫描限制保留，目录核对不等于全文逐页校审。

换版背景保留[苏州市政府说明](https://www.suzhou.gov.cn/szsrmzf/mszx/202608/15cfa67e4d9841128e27d99d4e344ea6.shtml)作参考；它不代替具体教材证据，也未取得覆盖所有学校的逐校配书清单。逐册文件名、SHA-256、对照入口、目录页和限制见 `config/book_evidence.json`，网页“版本与来源”也可查看。

## 维护与校验

Fork 分支分工、同步时机与验证流程见 [上游同步约定](docs/上游同步约定.md)。苏教版维护分支为 `suzhou-primary`；`origin` 指向用户 Fork，`upstream` 指向原项目。个人检查计划和部署运行记录保存在仓库之外。

```sh
python3 scripts/build.py
python3 scripts/build_preschool.py --check
node tests/test_preschool_ui.js
python3 -m unittest discover -s tests -p test_preschool_catalog.py
node tests/test_engine.js
node tests/test_suzhou.js
node tests/test_cloud.js
node tests/test_practice.js
node tests/test_practice_ui.js
python3 scripts/audit_questions.py
python3 -m unittest discover -s tests -p test_question_bank.py
python3 -m unittest discover -s tests -p test_public_boundary.py
python3 scripts/check_public_boundary.py
python3 scripts/check_public_boundary.py --history HEAD
```

云端模块测试及真实PostgreSQL、Keycloak验收的执行条件见对应模块说明。普通Maven验证不等于已经完成真实数据库联验；数据库测试必须显式指向可清空的隔离测试库。当前验证结果和浏览器检查范围见 [验证记录](docs/验证记录.md)。

可运行 `git config core.hooksPath .githooks` 启用推送前检查；检查失败时先处理公开内容边界。

数据层分开维护：

- `config/curriculum.py`：苏教目录、单元起始印刷页、概念映射、新概念与先修调整。
- `config/book_evidence.json`：逐册目录证据和质量限制；没有家庭隐私台账或本地绝对路径。
- `config/question_overrides.py`：重写练习与解释；正确选项构建时轮换位置。
- `config/question_supplements_{lower,middle,upper}.json`：新增固定题的题干、答案、解析、检查目标；数值题另有独立核算式。构建时追加稳定ID，不替换原题。
- `sources/upstream/`：原项目小学数据快照及原说明。原人教册次只留在来源元数据中，不作苏教版教学顺序。
- `scripts/build.py`：无网络、无 Vault 依赖的可重复构建；产物在 `data/`。
- `assets/model.js`：教材适配、先修顺序和版本化记录恢复。
- `config/practice_templates.json`、`data/practice_templates.json`：一至六年级认数、四则运算、分数小数、单位与时长、简易方程、周长面积及体积的独立变式清单。
- `assets/question-generators.js`、`assets/practice.js`：规则出题、题型族权重与冻结题序；独立于上游诊断引擎。
- `data/activities.json`：通用生活数学活动卡；云端保存观察时复制当时内容，不用新版补猜旧版玩法。
- `assets/cloud.js`、`assets/cloud-ui.js`：家庭上下文、云端保存、观察、历史、邀请及旧JSON迁移界面。
- `server/`、`identity-provider/`：独立业务服务和受控注册扩展；`deploy/`、`ops/` 提供通用部署、备份、恢复与健康检查工具。
- `diagnose/engine.js`：上游原诊断引擎。
- `docs/验证记录.md`：检查范围、UI截图与未完成内容。

新增一册时先补目录证据，再逐单元建立映射；同一概念可出现多次，不复制概念或改变稳定 ID。`printed_page` 是单元开始页，不是每个知识点的精确出处；不确定页码用空值。调整题目和数据后同步提升 `data_version`，防止旧练习记录混入新题库。

巩固与复习采用 `weighted-families-v1`：未练权重1，最近答错或暂时不会为3；最近答对为 `max(0.2, 1/(连续答对次数+1))`，7天内逐步回到1。候选充足时约80%用于未练或待巩固题型，20%用于已答对内容，不足时补齐。同一轮不重复相同题目。统计仅采用已保存的直接作答，排除观察、推断和旧JSON导入；它用于选题，不表示已经掌握。

版本2快照保存随机种子、策略与模板版本、权重及完整题序（含参数、题干、标准答案和解析）。刷新或换设备后从学习历史继续，不重新抽题；版本1诊断历史继续保留。接口不可用时明确提示重试，不绕过孩子画像另开一轮。

固定题库扩充不会把测试时生成的样本计入页面题量。首页分别显示898道实际固定题与70个变式模板；7万次生成核验只属于测试次数，其中包含重复变式。版本2的旧轮次仍按冻结题目继续，新题从新一轮开始使用；数据版本不同的版本1诊断保留历史查看，不按扩充后的题库重放。
