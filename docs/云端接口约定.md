# 云端家庭学习平台接口约定

云端运行根路径 `/edu/math`，API相对路径 `api/v1`。单独静态预览保留教材浏览，云端为学习历史唯一写入源。部署地址、身份中心配置、秘密和实际家庭数据不进入源码。

## 身份与响应

Java 25、Spring Boot 3.5.16、Spring Security OIDC、JDBC、Flyway，独立Maven模块 `server/`；PostgreSQL 18。身份以issuer/sub标识，角色OWNER、EDITOR、VIEWER按家庭分别授予。JSON直接返回资源或列表，错误采用ProblemDetail并附稳定code；401未登录、403无权限、404不可见资源、409并发或状态冲突。

- `GET capabilities` 公共，返回 `{cloud:true,adaptivePractice:true,apiVersion:1,loginUrl:"oauth2/authorization/learning"}`；有返回设备提示Cookie时增加 `sessionRestoreUrl:"oauth2/authorization/learning?restore=1"`。响应为 `Cache-Control:no-store`、`Vary:Cookie`，静态服务器404表示仅浏览。
- `GET csrf` 公共，返回 `{token,headerName}`，写入请求必须附该头，内部注册回调除外。
- `GET me` 返回 `{id,name,enabled,operator}`，无登录401。Cookie host-only、HttpOnly、Secure、SameSite=Lax；不把OIDC令牌交给JS。
- `GET/POST families`，创建体 `{name}`；返回 `{id,name,role}`。一个账号最多只有一个启用的家庭成员关系；已有家庭时创建返回409 `FAMILY_ALREADY_JOINED`，不创建空家庭。
- `GET/POST families/{familyId}/children`，创建体 `{nickname,stage}`；孩子资源 `{id,nickname,stage,archived,version}`。
- `PATCH families/{familyId}/children/{childId}`，携带version；仅OWNER管理档案。
- `GET families/{familyId}/members`；`PATCH .../members/{userId}`携带 `{role,active,version}`；不能移除最后一名OWNER。
- `GET/POST families/{familyId}/invitations`，创建体 `{role}`；返回 `{id,token,expiresAt}`，token仅创建时显示；`POST .../invitations/{id}/revoke`撤销。
- `POST operator/invitations` 创建入站邀请，仅部署配置明确绑定的运营身份可用；运营身份不自动访问其他家庭。
- `POST invitations/preview` 公共，体 `{token}`，验证但不消耗；`POST invitations/accept`登录后，体 `{token}`，原子加入家庭或获得建家资格。已有其他家庭或已有家庭时接受开户邀请均返回409 `FAMILY_ALREADY_JOINED`，邀请不被消耗；同一邀请成功后的重复请求维持幂等。
- `POST invitations/registration-grant` 公共，体 `{token}`，返回 `{grant,registrationUrl}`；仅有效邀请生成10分钟不透明授权。

## 学习资源

- `GET activities` 返回12张通用活动卡，每张 `{id,version,title,domain,materials,steps,parentPrompts,observe,easier,variation}`。
- `GET/POST families/{familyId}/children/{childId}/observations`，写入体 `{id,activityId,activityVersion,outcome,note,occurredAt,correctionOf}`；outcome为INDEPENDENT、PROMPTED、TOGETHER、NOT_TRIED、PAUSED。同id同内容幂等，不同内容409；更正追加且仅原作者或OWNER。
- `GET/POST families/{familyId}/children/{childId}/sessions`；创建 `{id,dataVersion,contentSnapshot,snapshot}`；`PUT .../sessions/{sessionId}` 传 `{version,snapshot,contentSnapshot,finished}`；保存返回 `{id,version,...}`，旧version409。
- `GET families/{familyId}/children/{childId}/practice-profile` 返回当前孩子的直接作答画像，结构见下节；逐请求检查成员与孩子归属，只读成员可读取，响应 `Cache-Control:no-store`。
- `GET families/{familyId}/children/{childId}/history`，可选cursor/limit，返回 `{items,nextCursor}`，默认50、最大100；项目包含 `{id,kind,occurredAt,authorName,...}`。历史不把引擎inferred作为长期掌握。
- `POST .../imports/preview` 校验旧JSON，体 `{record}`；`POST .../imports`体 `{id,record}`，显式目标家庭/孩子，保留旧内容快照，不伪造新版重新判分。
- `GET families/{familyId}/export`仅OWNER，JSON导出全部该家庭学习记录。

## 幼儿园活动与独立记录

独立页面入口 `/edu/kindergarten/`，复用同一成人身份、家庭、孩子、角色、CSRF与会话Cookie。匿名活动浏览使用公开静态目录 `data/preschool.json`；以下API和其他业务资源一样需要登录。

- `GET preschool/activities` 返回16张通用活动卡，包含 `module:PRESCHOOL`、稳定id与version、主题、材料、玩法、家长提示、观察方向、安全提醒、游戏来源和可确认剧集；家庭改编与原始游戏摘要分开。
- `GET/POST families/{familyId}/children/{childId}/preschool/observations`，写入体与数学观察相同。模块由服务端固定，不能通过请求体切换；同ID不同模块返回409，跨模块更正不可见。内容快照由服务器活动目录提供，客户端不能提交替换的活动正文。
- `GET families/{familyId}/children/{childId}/preschool/history` 使用cursor/limit分页，仅返回幼儿园观察；响应及每项带 `module:PRESCHOOL`。数学history只返回数学观察、练习和旧数学导入，带 `module:MATH`。
- 观察表与数据库结构沿用现有版本。模块保存在完整活动快照中，缺module的旧观察视为MATH，保留旧内容及幂等指纹；更正沿用原快照。新游标绑定模块，旧数学游标仍兼容，不能跨模块使用。
- 家庭总导出仍包含两模块的全部观察，可由module及快照识别归属。幼儿园观察不进入数学直接作答画像，不生成能力总分或诊断。

`capabilities`增加 `preschool:true`、`preschoolLoginUrl:oauth2/authorization/learning?module=preschool`；存在返回设备标记时增加对应 `preschoolSessionRestoreUrl:oauth2/authorization/learning?restore=1&module=preschool`。浏览器只接受这两个固定同源登录路径。

服务端把登录模块和恢复标志绑定对应OAuth state，最多保存8个、10分钟有效的会话内授权请求，保留原PKCE/nonce/受邀注册参数。幼儿园登录成功只回到固定的 `/edu/kindergarten/`，不接受任意外站或返回网址；并发标签互不覆盖。页面有未保存草稿时不自动导航，重新登录可在新页完成，再回草稿页重连。

## 随机巩固与孩子复习画像

画像响应 `{schema:1,dataVersion,asOf,topicIds,families,reviewQuestions}`；`dataVersion` 为当前教材数据版本，`asOf` 为本次读取时间。`topicIds` 仅列出现有题库或已发布变式模板仍兼容的直接尝试知识点。`families` 以 `fixed:<questionId>` 或 `template:<templateId>@<templateVersion>` 为键，每项 `{topicId,correct,wrong,skip,streak,lastResult,lastAt}`。数字变化后的同一模板共用统计；这些数值仅辅助选题，不代表完整掌握。

查询扫描该孩子所有已保存会话的最新快照，不受会话列表1000轮上限或历史分页影响。同一会话的同知识点、同题ID只计一项，跨会话再次练习正常累计；重复提交不额外累计。直接答案按时间排序，连续答对遇到错题或暂停不会时重置。新答案的 `answeredAt` 限于服务端会话开始与最近保存时间内，旧答案使用会话时间，未来时间不延长降权。导入、活动观察、推断、明确试运行标记均不纳入。

`reviewQuestions` 最多40道完整题目，不含用户作答原文。候选从全部合格历史按每请求随机优先级抽取不同原题，重复练习不增加同一道题的抽样机会。固定题须与当前题库的知识点、题型、题干、选项、标准答案及解释一致；动态题须匹配当前模板清单中的ID、版本及知识点。旧结果保留，不重新判分；不能兼容的原题仍留在历史里，但不加入自动复习。

新练习沿用会话创建、保存接口，使用版本2快照：

```json
{
  "schema": 2,
  "dataVersion": "curriculum-version",
  "mode": "practice",
  "seed": "random-seed",
  "startedAt": "2026-01-01T00:00:00Z",
  "targets": ["topic-id"],
  "limit": 10,
  "plan": [],
  "answers": [],
  "selection": {
    "strategyVersion": "weighted-families-v1",
    "catalogVersion": "template-catalog-version",
    "asOf": "2026-01-01T00:00:00Z",
    "weights": {}
  }
}
```

上例仅示意字段，实际 `plan` 必须含1至 `limit` 道完整题，`limit` 可选5、10、20；`mode` 为 `practice` 或 `review`。`contentSnapshot.questions` 必须与 `plan` 一致。每题保存题干、标准答案、解析和 `familyKey`；生成题另存 `templateId`、`templateVersion`、`params`。答案按题序追加 `{id:topicId,qid,result,text?,answeredAt,gradeSource,familyKey}`，`gradeSource` 为 `auto` 或 `manual`，不接受推断充作答题；服务端不重新计算旧题的数学答案。

创建时检查当前固定题和模板白名单；已创建的版本2会话固定题序、种子、策略、权重、范围和当时内容，不因后续题库升级重新生成。保存只追加答案，不能改写已保存答案或变更版本；兼容性升级也不阻止原会话按冻结题目完成。每个快照对象仍受500KB边界约束，继续使用原有幂等ID、版本冲突和结束后不可改写规则。版本1诊断会话及其恢复行为保持。

## 受控注册扩展

独立 `identity-provider/` Maven模块，匹配现有Keycloak 26.7.3。FormAction校验 `invite_grant`，只允许配置的教育客户端；复制并绑定带REQUIRED邀请门禁的注册流，其余客户端注册被拒绝。默认登录和既有Realm身份保持。所有校验失败默认拒绝，密码只在认证中心表单处理。

后端内部路径 `/internal/registration/reserve`、`/internal/registration/bind`，不在公开反代中开放；需 `X-Registration-Key`，仅内部注册集成使用。

- reserve体 `{grant,clientId,authSessionId,username}`，返回 `{reservationId}`；同一grant绑定同一认证会话和username，重复一致请求可重试。
- bind体 `{reservationId,clientId,authSessionId,issuer,subject}`；成功仅绑定已创建身份，不直接授予家庭权限；相同绑定可重试，不同身份409。
- FormAction在User Creation之后执行，validate阶段预留，success阶段在同一个Keycloak身份事务中写入 `learning_registration_receipt`；事务成功提交后才通过afterCompletion尝试bind。身份回滚时不外呼绑定，bind失败或响应丢失时保留已提交身份，通过正常登录续办。
- 收据格式为 `base64url(JSON).base64url(HMAC-SHA256(key,payloadBase64ASCII))`，JSON包含v=1、reservationId、clientId、authSessionId、issuer、subject。只将该属性映射到教育客户端的同名ID token claim；后端仅从已验证OIDC身份中核签并幂等续绑，不按用户名识别。预留过期后保留历史定位，允许已提交账号续办；邀请撤销、过期或已由其他身份领取仍拒绝授权。
- 用户完成OIDC后显式接受邀请；有绑定时必须匹配登录身份。账号创建但后续入家失败可再次登录续办，完成前无业务权限。

## 持久化边界

家庭业务行携带family_id、child_id，用复合外键约束父子归属，RLS和接口双重检查。数据库迁移与Web运行角色分离，运行角色非owner、非superuser、无BYPASSRLS，身份上下文为事务内设置。成员撤销逐请求生效，原署名保留。家庭成员表以启用状态的部分唯一索引约束每账号仅一个家庭；创建、加入与重新启用成员均受此约束。退出或被移除后可以重新选择家庭，但不能退出或降级最后一名管理员。邀请7天、单次消费、只存摘要。实际生产数据不用作测试夹具。

## 记住我与自动恢复

Keycloak原生“记住我”仅在用户勾选后保存30天持久SSO，最长30天从该次完整登录开始计算，不因学习站自动恢复而无限延长。未勾选者保留普通Realm时长；学习站本地会话仍闲置60分钟失效。

成功OIDC登录设置 `LEARNING_RETURNING=1`，有效30天、host-only、Secure、HttpOnly、SameSite=Lax、应用路径。它只提示发起真实OIDC验证，不包含身份或令牌，也不授予权限。前端仅首次启动的 `me` 返回401且有能力提示时自动发起一次标准授权码流程（`prompt=none`、state/nonce/S256）；过期或撤销后清提示并返回家庭页，普通访客不循环跳转。保存过程的401保留本页待保存内容，不自动离开。

主动退出清除提示Cookie并沿用统一退出机制。当前普通登录要改为“记住我”时，页面提供明确说明的退出入口，经CSRF POST退出后再完整登录选择；Keycloak已识别用户时的密码重验页面不能修改“记住我”，不以 `prompt=login` 冒充完成启用。
