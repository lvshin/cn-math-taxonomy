# 云端家庭学习平台接口约定

云端运行根路径 `/edu/math`，API相对路径 `api/v1`。单独静态预览保留教材浏览，云端为学习历史唯一写入源。部署地址、身份中心配置、秘密和实际家庭数据不进入源码。

## 身份与响应

Java 25、Spring Boot 3.5.16、Spring Security OIDC、JDBC、Flyway，独立Maven模块 `server/`；PostgreSQL 18。身份以issuer/sub标识，角色OWNER、EDITOR、VIEWER按家庭分别授予。JSON直接返回资源或列表，错误采用ProblemDetail并附稳定code；401未登录、403无权限、404不可见资源、409并发或状态冲突。

- `GET capabilities` 公共，返回 `{cloud:true,apiVersion:1,loginUrl:"oauth2/authorization/learning"}`；静态服务器404表示仅浏览。
- `GET csrf` 公共，返回 `{token,headerName}`，写入请求必须附该头，内部注册回调除外。
- `GET me` 返回 `{id,name,enabled,operator}`，无登录401。Cookie host-only、HttpOnly、Secure、SameSite=Lax；不把OIDC令牌交给JS。
- `GET/POST families`，创建体 `{name}`；返回 `{id,name,role}`。
- `GET/POST families/{familyId}/children`，创建体 `{nickname,stage}`；孩子资源 `{id,nickname,stage,archived,version}`。
- `PATCH families/{familyId}/children/{childId}`，携带version；仅OWNER管理档案。
- `GET families/{familyId}/members`；`PATCH .../members/{userId}`携带 `{role,active,version}`；不能移除最后一名OWNER。
- `GET/POST families/{familyId}/invitations`，创建体 `{role}`；返回 `{id,token,expiresAt}`，token仅创建时显示；`POST .../invitations/{id}/revoke`撤销。
- `POST operator/invitations` 创建入站邀请，仅部署配置明确绑定的运营身份可用；运营身份不自动访问其他家庭。
- `POST invitations/preview` 公共，体 `{token}`，验证但不消耗；`POST invitations/accept`登录后，体 `{token}`，原子加入家庭或获得建家资格。
- `POST invitations/registration-grant` 公共，体 `{token}`，返回 `{grant,registrationUrl}`；仅有效邀请生成10分钟不透明授权。

## 学习资源

- `GET activities` 返回12张通用活动卡，每张 `{id,version,title,domain,materials,steps,parentPrompts,observe,easier,variation}`。
- `GET/POST families/{familyId}/children/{childId}/observations`，写入体 `{id,activityId,activityVersion,outcome,note,occurredAt,correctionOf}`；outcome为INDEPENDENT、PROMPTED、TOGETHER、NOT_TRIED、PAUSED。同id同内容幂等，不同内容409；更正追加且仅原作者或OWNER。
- `GET/POST families/{familyId}/children/{childId}/sessions`；创建 `{id,dataVersion,contentSnapshot,snapshot}`；`PUT .../sessions/{sessionId}` 传 `{version,snapshot,contentSnapshot,finished}`；保存返回 `{id,version,...}`，旧version409。
- `GET families/{familyId}/children/{childId}/history`，可选cursor/limit，返回 `{items,nextCursor}`，默认50、最大100；项目包含 `{id,kind,occurredAt,authorName,...}`。历史不把引擎inferred作为长期掌握。
- `POST .../imports/preview` 校验旧JSON，体 `{record}`；`POST .../imports`体 `{id,record}`，显式目标家庭/孩子，保留旧内容快照，不伪造新版重新判分。
- `GET families/{familyId}/export`仅OWNER，JSON导出全部该家庭学习记录。

## 受控注册扩展

独立 `identity-provider/` Maven模块，匹配现有Keycloak 26.7.3。FormAction校验 `invite_grant`，只允许配置的教育客户端；复制并绑定带REQUIRED邀请门禁的注册流，其余客户端注册被拒绝。默认登录和既有Realm身份保持。所有校验失败默认拒绝，密码只在认证中心表单处理。

后端内部路径 `/internal/registration/reserve`、`/internal/registration/bind`，不在公开反代中开放；需 `X-Registration-Key`，仅内部注册集成使用。

- reserve体 `{grant,clientId,authSessionId,username}`，返回 `{reservationId}`；同一grant绑定同一认证会话和username，重复一致请求可重试。
- bind体 `{reservationId,clientId,authSessionId,issuer,subject}`；成功仅绑定已创建身份，不直接授予家庭权限；相同绑定可重试，不同身份409。
- FormAction在User Creation之后执行，validate阶段预留，success阶段在同一个Keycloak身份事务中写入 `learning_registration_receipt`；事务成功提交后才通过afterCompletion尝试bind。身份回滚时不外呼绑定，bind失败或响应丢失时保留已提交身份，通过正常登录续办。
- 收据格式为 `base64url(JSON).base64url(HMAC-SHA256(key,payloadBase64ASCII))`，JSON包含v=1、reservationId、clientId、authSessionId、issuer、subject。只将该属性映射到教育客户端的同名ID token claim；后端仅从已验证OIDC身份中核签并幂等续绑，不按用户名识别。预留过期后保留历史定位，允许已提交账号续办；邀请撤销、过期或已由其他身份领取仍拒绝授权。
- 用户完成OIDC后显式接受邀请；有绑定时必须匹配登录身份。账号创建但后续入家失败可再次登录续办，完成前无业务权限。

## 持久化边界

家庭业务行携带family_id、child_id，用复合外键约束父子归属，RLS和接口双重检查。数据库迁移与Web运行角色分离，运行角色非owner、非superuser、无BYPASSRLS，身份上下文为事务内设置。成员撤销逐请求生效，原署名保留。邀请7天、单次消费、只存摘要。实际生产数据不用作测试夹具。
